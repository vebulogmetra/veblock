# Veblock

Прокси-клиент для Linux, Windows и Android на базе [xray-core](https://github.com/XTLS/Xray-core).

[Скачать](https://github.com/vebulogmetra/veblock/releases)

</div>

## Установка

### Linux

Скачайте `tenga-proxy_<версия>_amd64.deb` из релиза с тегом `linux-v…` и
установите:

```bash
sudo apt install ./tenga-proxy_<версия>_amd64.deb
```

### Windows

Скачайте `veblock-<версия>-windows-x64-setup.exe` из релиза с тегом
`windows-v…` и запустите. Нужны Windows 10 или 11 (x64) и права
администратора на время установки.

### Android

Скачайте `veblock-<версия>-android.apk` из релиза с тегом `android-v…` и
откройте на телефоне. Нужен Android 7 или новее; установку из браузера или
файлового менеджера придётся разрешить в настройках.

## Обновления

Приложение раз в день проверяет релизы этого репозитория и смотрит только
теги своей платформы. Windows- и Android-версии умеют обновляться сами,
Linux-версия показывает ссылку на релиз.
