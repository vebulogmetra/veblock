# Veblock

Прокси-клиент для Linux и Windows на базе [xray-core](https://github.com/XTLS/Xray-core).

[Скачать](https://github.com/vebulogmetra/veblock/releases)

</div>

Здесь публикуются релизы Veblock для настольных систем. Исходный код в
этом репозитории не хранится.

## Установка

### Linux

Скачайте `tenga-proxy_<версия>_amd64.deb` из релиза с тегом `linux-v…` и
установите:

```bash
sudo apt install ./tenga-proxy_<версия>_amd64.deb
```

### Windows

Скачайте `veblock-<версия>-windows-x64-setup.exe` из релиза с тегом
`windows-v…` и запустите. Нужны Windows 10 или 11 (x64) и права
администратора на время установки.

## Обновления

Приложение раз в день проверяет релизы этого репозитория и смотрит только
теги своей платформы. Windows-версия умеет обновляться сама, Linux-версия
показывает ссылку на релиз.
